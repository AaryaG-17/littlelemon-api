Menu API

Browse menu items publicly. Staff and users in the Manager group can create, update, and delete menu items.

GET /api/menu/

Booking API

Authenticated users can create and manage their own bookings. Staff can review all bookings.

GET /api/bookings/

Authentication

Register an account, then obtain an API token for protected endpoints.

POST /api-token-auth/
